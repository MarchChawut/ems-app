# เริ่มต้นใช้งาน (สำหรับหน่วยงานที่ติดตั้งระบบ)

ระบบนี้ออกแบบให้ **แต่ละหน่วยงานติดตั้งชุดของตัวเอง** — จำนวนบัญชีผู้ใช้ = กำลังพลจริงของหน่วยงานนั้น
ระบบไม่มีรายชื่อพนักงาน/บัญชีตัวอย่าง/รหัสผ่านตัวอย่างมาให้ เพื่อให้มีบัญชีน้อยที่สุดและไม่มีช่องโหว่จากบัญชีเริ่มต้น

## 1) ติดตั้ง

```bash
pnpm install
cp .env.example .env          # แล้วแก้ค่าใน .env (อย่างน้อย DATABASE_URL, TWO_FACTOR_ENC_KEY, CRON_SECRET, SEED_ADMIN_PASSWORD)
pnpm prisma migrate deploy    # สร้างตารางทั้งหมด
pnpm db:seed                  # สร้างข้อมูลเริ่มต้น + Super Admin 1 บัญชี
pnpm dev                      # หรือ pnpm build && pnpm start
```

`pnpm db:seed` สร้าง **เฉพาะ**: ข้อมูลหน่วยงาน (ชื่อตัวอย่าง แก้ภายหลังได้), คอลัมน์งานเริ่มต้น, แม่แบบฟอร์มระบบ, สิทธิ์ค่าเริ่มต้นตามบทบาท
และ **Super Admin 1 บัญชี** (ชื่อผู้ใช้จาก `SEED_ADMIN_USERNAME`) — รันซ้ำได้ปลอดภัย ไม่เขียนทับของเดิม

## 2) เข้าสู่ระบบครั้งแรก

1. เข้าสู่ระบบด้วย Super Admin ที่ seed สร้าง (รหัสผ่านจาก `SEED_ADMIN_PASSWORD` หรือรหัสที่สุ่มให้และแสดงตอนรัน seed)
2. ระบบบังคับ **เปลี่ยนรหัสผ่าน** และ **ลงทะเบียน passkey** (ถ้าติดตั้งบนโดเมน HTTPS) ก่อนใช้งานส่วนอื่น — รหัสเริ่มต้นหมดอายุใน 7 วัน
3. เปิดการยืนยันตัวตนสองชั้น (2FA) ที่หน้า ตั้งค่า

## 3) ตั้งค่าหน่วยงาน

- **ตั้งค่า > ข้อมูลหน่วยงาน**: ใส่ชื่อสังกัดและชื่อกองของหน่วยงานคุณ (ใช้เป็นหัวกระดาษของทุกแบบฟอร์ม)
- **ตั้งค่า > ฟีเจอร์ของระบบ** (เฉพาะ Super Admin): ติดตั้งใหม่เริ่มด้วยแท็บหลัก (หน้าหลัก / พนักงาน / ตั้งค่า + ข้อมูลส่วนตัวในเมนูรูปโปรไฟล์)
  เปิดฟีเจอร์เสริมที่ต้องใช้ (การลา, ตารางเวร, หนังสือเข้า-ออก, แบบฟอร์ม, วัสดุ, ครุภัณฑ์, ติดตามงาน) และตั้งค่าเริ่มต้นของแต่ละฟีเจอร์ — ดู [FEATURES.md](./FEATURES.md)

## 4) เพิ่มพนักงาน

- ทีละคน: หน้า **พนักงาน** → เพิ่มพนักงาน (ระบบตั้งรหัสเริ่มต้นให้ ผู้ใช้ต้องเปลี่ยนตอนล็อกอินครั้งแรก)
- ทั้งหมดพร้อมกัน: หน้า **พนักงาน** → นำเข้า CSV ตามไฟล์ตัวอย่าง [`employees-import-template.csv`](./employees-import-template.csv)
  (คอลัมน์ `name,email,username,role,department`; ตัวอย่างในไฟล์เป็นข้อมูลสมมติ)
- บุคคลที่มาช่วยราชการจากหน่วยอื่น: ตั้ง กอง/สังกัด เป็น "อื่นๆ (ช่วยราชการ)" ในหน้าแก้ไขพนักงาน

## 5) ความปลอดภัย

ดู [SECURITY.md](./SECURITY.md) — ห้าม commit `.env` จริง, ตั้ง HTTPS + passkey ในการใช้งานจริง, หมุนความลับเมื่อจำเป็น
